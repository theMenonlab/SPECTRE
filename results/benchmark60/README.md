# Historical 60-channel benchmark

`BIG_results_standard_every20_60ch.csv` and `experiment_summary.json` preserve the compact architecture-comparison results. The selected SPECTRE configuration reported 46.7197804428494 dB PSNR and 0.9838920125366212 3D-SSIM on the 10,202-pair standard split.

The exact final-minus-anchor checkpoint supporting that row was not available at the audited source path when this release was prepared. It is therefore not claimed or replaced by a similarly named weight. The benchmark's third-party model source trees, including SPECAT, are also not redistributed here. These files are result provenance, not a self-contained rerun of all benchmark architectures.
