# Superseded July 30 records

These evaluation and throughput records belong to the July 30 Model A, B and C checkpoints
(SHA-256 prefixes 9b1ff586, 0daceea3 and 6fa0bc3c) and the July calibration tensor (c1426c8f).
Those checkpoints were replaced in Kaggle model version 4 and remain available as version 3 of the
`default` variation. The current records are in the parent folder.
